LAN Touchpad Windows 桌面端

安装：运行 LAN-Touchpad-Setup-v*.exe，按向导选择安装目录和快捷方式。
默认目录：C:\Program Files\LAN Touchpad
默认创建桌面快捷方式、开始菜单快捷方式、登录 Windows 自动启动，并在安装完成后启动。

数据保存：接收文件保存在 %LOCALAPPDATA%\LAN Touchpad\received。升级和卸载不会自动删除这些文件。

使用：启动 LAN Touchpad，查看窗口中的 ws://IPv4:8765 地址；Android 设备需与电脑处于同一可信局域网。
安全：本程序没有账号、配对码或 TLS。只在可信专用网络使用，不要设置路由器端口转发，也不要在公共 Wi-Fi 使用。Windows 防火墙只允许专用网络访问 TCP 8765。

虚拟手柄：需要兼容的 ViGEmBus 驱动；未安装驱动时，屏幕、鼠标、键盘和文件传输功能仍可使用。
